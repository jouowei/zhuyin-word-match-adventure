# 認字大冒險 🚀

給 5～7 歲孩子的注音、國字、英文學習遊戲。參考兒童學習研究設計：孩子卡住時才一步步給提示，會了就慢慢把提示拿掉，讓孩子真正自己學會。

👉 **線上玩：** https://zhuyin-word-match-adventure-rasdygd6xa-uw.a.run.app

> 從 LINE 分享連結時，請在網址後面加上 `?openExternalBrowser=1`。LINE 內建的瀏覽器沒有語音朗讀，會聽不到中文說明。

## ✨ 特色

### 🎧 自然的英文語音
- 用開源語音模型 Kokoro-82M 製作了 306 段美式英文音檔，內容包括字母、自然發音、單字和句子。
- 每段都經過 Whisper 語音辨識確認念得正確。
- 手機、平板、電腦聽起來都一樣，不依賴裝置的電腦語音。
- 「慢慢唸」會放慢速度，但音調不變。

### 📖 和課本一樣的注音排版
- 國字用標準楷書，注音由字型直接排在字的右邊（Bpmf Zihi Kai Std）。
- 破音字依詞語選讀音，家長也能自己指定。
- 注音符號與詞語錄音來自教育部資料，全部是台灣標準讀音。

### 🪜 鷹架式提示
答錯時一步步幫忙：先再聽一次 → 選項變少 → 最後才提示答案。自己答對 +10 分，用了提示 +2 分。

### 🔁 間隔複習
學過的字隔 1、3、7、14、30 天再出現，答錯的字很快回來練習。

## 🎮 遊戲內容

**選好角色後，兩條路**
- **🗺️ 環島冒險（學習遊戲）：** 跟著夥伴環遊台灣。
- **📖 練習課文：** 先選學期（一年級上學期…六年級下學期），再挑一課，聽課文、玩課文尋寶、玩這一課的生字遊戲。寫功課、複習課文時用。
  - 一年級上學期到六年級下學期，每學期內建 4 篇為這個遊戲寫的原創短文（共 48 篇，`lessons/`），長度和用字照年級慢慢增加（一上約 35 字，六下約 400 字）。
  - 家長也可以照自己的課本輸入課文（家長專區 → 管理課文），標上年級、學期和第幾課。課本內容有著作權，程式裡不附課本課文。
  - 課文頁的字會自動縮放，長句子在手機上也一頁放得下。

**環島冒險**
- **冒險夥伴：** 孩子挑一隻夥伴（小狐狸、小熊、小龍、小兔），由牠說話帶路，不識字也能玩。
- **環島地圖：** 每天第一次完成中文或英文冒險，就往前走一段，兩段到下一個地方：基隆港 → 台北 → 新竹 → 苗栗 → 台中 → 日月潭 → 阿里山 → 台南 → 高雄 → 墾丁 → 台東 → 花蓮 → 宜蘭 → 九份 → 回到基隆。每到一個地方有一段小故事和當地的朋友，離開時拿到紀念品。
- **會長大的花園：** 練過的注音會長成花、國字長成樹、英文從蛋孵成動物；複習時記得，就長大一點。點一下會念出那個字。
- **一個按鈕出發：** 按「出發」就開始今日冒險，練的內容由家長設定。
- **遊樂場：** 完成今天的冒險後開門，可以自己挑喜歡的遊戲。
- 所有畫面和關卡在手機直拿、橫拿和平板上都是一個畫面放得下，不用捲動。

**國字與注音**
- **今日冒險（約 10 分鐘）：** 暖身複習 → 認識新朋友 → 練習 → 挑戰 → 今天的成果。
- **8 種關卡：** 字卡大冒險、聽力大師、小小書法家、小小播音員、拼音高手、聲調偵探、字的家族、部件偵探。
- **小小播音員（注音）：** 錄音比一比。孩子念完，先放標準發音再放自己的聲音，一樣就按大拇指。單獨一個注音手機的語音辨識聽不準，所以注音不用語音辨識；國字詞語和英文仍用語音辨識。
- **寫字：** 描紅 → 看起筆點寫 → 自己寫 → 聽音寫，逐步減少協助。
- **課文：** 家長輸入課文，孩子聽課文、玩「課文尋寶」。

**英文大冒險**
- **學習內容：** 字母與自然發音、短母音、長母音、魔法 e、主題單字（顏色、數字、動物、食物…）。
- **寫字母：** 在四線格上照筆順寫。
- **練習玩法：** 拼字前先聽聲音拆解、押韻家族、句子尋寶、開口說英文。

**家長功能**
- **家長專區：** 設定孩子練什麼（注音、某一課或所有課文）、管理課文和自訂英文單字、完成實體任務時給星星、換冒險夥伴；還有學習週報、容易混淆的字、陪玩與共讀建議。
- **家長密碼：** 第一次進入家長功能時才設定；家長專區和刪除角色都需要密碼。
- **卡片商店：** 可以用點數抽卡，每學會 10 個字另外送一張卡片。

進度存在瀏覽器裡（localStorage），不會上傳到伺服器；換裝置或換瀏覽器就是新的進度。

**加到主畫面與離線模式**
- 可以把遊戲「加到主畫面」，像 App 一樣從桌面打開（也能避開 LINE 內建瀏覽器聽不到聲音的問題）。
- 在「家長專區」開啟離線模式：會先下載音檔、字型、國字筆順和課文詞語的錄音（約 35 MB），全部下載完成才算開啟，之後沒有網路也能玩。
- 教育部詞語錄音只在這台裝置保存詞語本身（和遊戲播放的一樣），不含整段解釋；伺服器轉送的原始檔案不做任何修改。
- 本機試離線模式：`npm run build` 後執行 `node scripts/serve-prod.mjs`（http://localhost:3001），因為離線功能只在正式版啟用。

## 🛠️ 本機執行

需要 Node.js 22 以上。

```bash
npm install
npm run dev
npm test      # 學習邏輯的測試
```

開啟 http://localhost:3000 。

AI 產生圖片、自訂英文單字自動補齊需要 Gemini API 金鑰：在專案根目錄建立 `.env.local`，寫入 `GEMINI_API_KEY=你的金鑰`。沒有金鑰也能玩，只是這些功能不能用。

## 📁 專案結構

| 路徑 | 內容 |
|---|---|
| `App.tsx` | 把各部分接起來，決定顯示哪個畫面 |
| `hooks/` | 遊戲流程：玩家資料、答題紀錄、中文與英文關卡、課文與句子、今日冒險 |
| `components/` | 畫面與遊戲 |
| `services/` | 規則與資料：答題計分、學習紀錄、間隔複習、今日冒險、家長報告、部件資料 |
| `tests/` | `npm test` 執行的測試 |
| `utils/` | 音訊播放（錄音、英文音檔、放慢）、筆畫比對 |
| `zhuyin/`、`english/` | 注音與英文課程資料 |
| `server.ts` | Express 伺服器：網頁、萌典錄音轉送、Gemini API |
| `public/audio/` | 注音符號、詞語、英文音檔 |
| `scripts/` | 產生注音資料、字型破音字表、英文音檔的工具 |

英文音檔的重新產生方式見 [scripts/english-audio/README.md](scripts/english-audio/README.md)。

## 🚢 部署

目前部署在 Google Cloud Run（us-west1）。

```bash
npm run build
npm start
```

伺服器會使用環境變數 `PORT`，沒有設定時用 3000。
