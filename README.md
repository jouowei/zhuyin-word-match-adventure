# 認字大冒險 🚀

給 5～7 歲孩子的注音、國字、英文學習遊戲。參考兒童學習研究設計：孩子卡住時才一步步給提示，會了就慢慢把提示拿掉，讓孩子真正自己學會。

👉 **線上玩：** https://zhuyin-word-match-adventure-rasdygd6xa-uw.a.run.app

> 從 LINE 分享連結時，請在網址後面加上 `?openExternalBrowser=1`。LINE 內建的瀏覽器沒有語音朗讀，會聽不到中文說明。

## ✨ 特色

### 🎧 自然的英文語音
- 用開源語音模型 Kokoro-82M 製作了 306 段美式英文音檔，內容包括字母、自然發音、單字和句子。
- 每段都經過 Whisper 語音辨識確認念得正確。
- 手機、平板、電腦聽起來都一樣，不依賴裝置的電腦語音。
- 「慢慢唸」會放慢速度，但音調不變。

### 📖 和課本一樣的注音排版
- 國字用標準楷書，注音由字型直接排在字的右邊（Bpmf Zihi Kai Std）。
- 破音字依詞語選讀音，家長也能自己指定。
- 注音符號與詞語錄音來自教育部資料，全部是台灣標準讀音。

### 🪜 鷹架式提示
答錯時一步步幫忙：先再聽一次 → 選項變少 → 最後才提示答案。自己答對 +10 分，用了提示 +2 分。

### 🔁 間隔複習
學過的字隔 1、3、7、14、30 天再出現，答錯的字很快回來練習。

## 🎮 遊戲內容

**國字與注音**
- **今日冒險（約 10 分鐘）：** 暖身複習 → 認識新朋友 → 練習 → 挑戰 → 今天的成果。
- **8 種關卡：** 字卡大冒險、聽力大師、小小書法家、小小播音員、拼音高手、聲調偵探、字的家族、部件偵探。
- **寫字：** 描紅 → 看起筆點寫 → 自己寫 → 聽音寫，逐步減少協助。
- **課文模式：** 家長輸入課文，孩子聽課文、玩「課文尋寶」。

**英文大冒險**
- **學習內容：** 字母與自然發音、短母音、長母音、魔法 e、主題單字（顏色、數字、動物、食物…）。
- **寫字母：** 在四線格上照筆順寫。
- **練習玩法：** 拼字前先聽聲音拆解、押韻家族、句子尋寶、開口說英文。

**家長功能**
- **家長專區：** 學習週報、容易混淆的字、陪玩與共讀建議。
- **家長密碼：** 第一次使用時設定；領取實體任務獎勵和刪除角色都需要密碼。
- **卡片商店：** 可以用點數抽卡，每學會 10 個字另外送一張卡片。

進度存在瀏覽器裡（localStorage），不會上傳到伺服器；換裝置或換瀏覽器就是新的進度。

## 🛠️ 本機執行

需要 Node.js 22 以上。

```bash
npm install
npm run dev
```

開啟 http://localhost:3000 。

AI 產生圖片、自訂英文單字自動補齊需要 Gemini API 金鑰：在專案根目錄建立 `.env.local`，寫入 `GEMINI_API_KEY=你的金鑰`。沒有金鑰也能玩，只是這些功能不能用。

## 📁 專案結構

| 路徑 | 內容 |
|---|---|
| `App.tsx`、`components/` | 畫面與遊戲 |
| `services/` | 學習紀錄、間隔複習、今日冒險、家長報告、部件資料 |
| `utils/` | 音訊播放（錄音、英文音檔、放慢）、筆畫比對 |
| `zhuyin/`、`english/` | 注音與英文課程資料 |
| `server.ts` | Express 伺服器：網頁、萌典錄音轉送、Gemini API |
| `public/audio/` | 注音符號、詞語、英文音檔 |
| `scripts/` | 產生注音資料、字型破音字表、英文音檔的工具 |

英文音檔的重新產生方式見 [scripts/english-audio/README.md](scripts/english-audio/README.md)。

## 🚢 部署

目前部署在 Google Cloud Run（us-west1）。

```bash
npm run build
npm start
```

伺服器會使用環境變數 `PORT`，沒有設定時用 3000。
